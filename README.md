# RAI
Личная кошкодевочка под любые вкусы в телеграмм :3

1. Полностью приватна и настраиваема, работает на железе компьютера(личного сервера если есть)
2. Моделька ИИ работает в olama приложении, где передает данные на локальный сервер localhost
3. Исполняемый файл обрабатывает работу с Telegram и отправляет запросы к нейросети в локальном сервере

Из особенностей, отправка ответа ИИ идет через стриминг, а в Telegram поэтапно отправляется запрос редактированния сообщения-ответа
